# Node.jsの基礎を学ぶハンズオン

プロセスとスレッド、JSのビルド、Node.jsだけで作るWeb版TODOを順に学びます。目的は、動いた理由と、ツールやフレームワークが引き受けている仕事を自分の言葉で説明できるようになることです。

## 教材

| 順番 | 教材 | 到達目標 |
| --- | --- | --- |
| 1 | [プロセスとスレッドを観察する](lessons/01-process-and-thread.md) | 識別番号と値の変化から違いを説明する |
| 2 | [同じJSを3つのツールでビルドする](lessons/02-build-tools.md) | 構文の変換とファイルの結合を区別する |
| 3 | [Node.jsだけでWeb版TODOを作る](lessons/03-node-todo.md) | 一件の追加処理を入口から出口まで追う |

課題文から推測すると、3つの宿題は「プログラムの実行」「コードの変換と結合」「Webアプリの処理」を理解するためのものです。出題者の意図そのものを確認した記録ではありません。原文のesbuldはesbuildとして扱います。

TODOの形式は出題者から指定されていません。この教材ではHTTPを学ぶためにWeb版を作り、Node.jsの標準機能と素のHTML・JSを使います。Express、React、データベースは使いません。

## 始め方

macOSのターミナル、エディタ、Node.js、npm、ブラウザを使います。このREADMEがある`nodejs-homework`フォルダをターミナルとエディタで開き、[最初の教材](lessons/01-process-and-thread.md)へ進んでください。ビルドツールの対応バージョンと導入手順は2つ目の教材で案内します。

説明→予想→実行→観察→説明し直す、の順に1課題ずつ進めます。対話で進める場合は、予想への回答や実行結果を伝えてから次へ進みます。各課題の時間は目安です。

## ファイルの置き方

- `lessons/`：説明、実行手順、観察ポイント、記録の書き方。
- `examples/`：教材から参照する実行用コード。TODOは課題7〜11の段階ごとに用意。
- 練習用ファイル：各教材の案内に従って、リポジトリ直下や`src/`、`todo/`へコピー・編集。

生成物は`dist/`へ置きます。サーバーを使う課題では、自分で起動した練習用サーバーをCtrl+Cで終了してください。
